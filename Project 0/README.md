# Project 0 - Farmers Market

A simple shopping app made with React. The items are hard coded. You can buy one item at a time and pay on a fake credit card checkout page.

## How to run
```
npm install
npm run dev
```

## What it does
- Shows 6 items for sale
- Click Buy to go to the checkout page
- Checks the name, card number, expiration date, and CVV
- Card number is checked with the Luhn algorithm
- Shows a thank you page after a good payment

Test card number: 4242 4242 4242 4242 (any future date, any 3 digit CVV)
